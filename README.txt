중학교 정보 실습 워크북 홈페이지

1. 이 폴더 안의 파일을 모두 같은 웹 호스팅 경로에 올립니다.
2. 시작 주소는 index.html입니다.
3. 마이크로비트 수업은 1~8차시로 구성되어 있으며 무선 통신 차시를 포함합니다.
4. 리스트·함수·디버깅 차시에 「더 나아가기」 활동을 추가했습니다.
5. 학생이 입력한 기록은 해당 브라우저의 localStorage에 자동 저장됩니다.
6. 실행 결과 예상하기는 학생이 예상 결과와 이유를 모두 입력한 뒤 예시 답안과 비교하는 방식입니다.
7. 예시 답안은 인쇄할 때 포함되지 않습니다.
